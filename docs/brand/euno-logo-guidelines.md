# Euno Logo Guidelines

## 品牌主张

Euno 是进入个人 Web 世界的安静数字入口。主标志以圆角门户承载负空间 `E`：先读作独立的空间符号，再从三道阈值中辨认出字母。

## 资产与选择

- `concept-01` 至 `concept-06` 为六个黑白探索方向，分别对应 Abstract E、Portal、Negative Space、Continuous Path、E + Dot、E + Connection。
- `euno-icon.svg` 为生产主方案（负空间入口、品牌渐变）；`finalist-02-continuous-path.svg` 为深化备选方案。
- `euno-horizontal*.svg` 是图形与定制路径字标的横向组合；`euno-wordmark*.svg` 提供黑、白、蓝和渐变字标单独版。

## 色彩与使用

- 墨黑：`#111827`；主蓝：`#2563EB`；柔紫：`#7C5CFF`。
- 浅色背景使用 `euno-horizontal-black.svg`；深色背景使用 `euno-horizontal-white.svg`；产品默认使用 `euno-horizontal.svg`。
- `euno-icon.svg` 用于 favicon、App Icon、头像与紧凑导航。图形最小 16px，推荐不低于 24px；横向组合最小宽度 120px。
- 四周至少保留图标边长的 25% 空白。不得描边、旋转、加阴影或将渐变作为唯一可识别信息。

## 可访问性

图形单独使用时提供 `Euno` 文本替代；装饰性展示使用空 `alt` 并由相邻文字提供品牌名。
